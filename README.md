# 🎯 BuildX Lead Finder (مسئله ۱: کاشف هوشمند مشتری بالقوه)

سامانه هوشمند کشف و تحلیل لیدهای فروش در جوامع آنلاین با قلب ایجنتیک، پیاده‌سازی‌شده برای مسابقه استارتاپی BuildX (کوئرا).

---

## 📌 درباره پروژه
بسیاری از کسب‌وکارها در میان انبوه پیام‌ها و گفتگوهای شبکه‌های اجتماعی و جوامع آنلاین، فرصت‌های فروش واقعی را از دست می‌دهند. این پروژه یک ایجنت هوشمند است که:
1. پیام‌های کاربران در جوامع آنلاین را دریافت و تحلیل می‌کند.
2. میزان تناسب (Fit Score) نیاز کاربر را با محصول یا کسب‌وکار شما می‌سنجد.
3. در صورت تناسب، پاسخ پیشنهادی مناسب برای ارتباط و جذب مشتری تولید می‌کند.
4. هزینه تخمینی پردازش هر پیام را به صورت شفاف گزارش می‌دهد.

---

## 🛠️ تکنولوژی‌ها و معماری فنی
* **زبان برنامه‌نویسی:** پایتون (Python)
* **رابط کاربری (UI):** استریم‌لیت (Streamlit) برای پیاده‌سازی سریع، واکنش‌گرا و کاربردی MVP
* **هسته هوش مصنوعی / ایجنت:** مدل‌های زبانی بزرگ (LLM) از طریق ارائه‌دهندگان سرویس ابری
* **مدیریت نشست (Session Management):** پیاده‌سازی جریان ورود و احراز هویت مینیمال کاربران
